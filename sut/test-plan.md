# Module B - test plan

The app under test is the delivered WSC2024 Skill 17 Module B build. This plan is written from
`docs/spec.md`, not from what the build actually does. Every row says which spec rule it comes
from and which test covers it.

Suites: `tests/Unit` (no db, no http), `tests/Feature` (http + sqlite in memory),
`tests/Security` (http, one file per security rule `S1`-`S8`).

Feature and security tests use RefreshDatabase and factories only: no seed data, no order between
tests, no dependency on today's date. Upload tests use `Storage::fake('public')`, login tests
clear `login:127.0.0.1` first.

Test names are written as `<file>::<test name>`.
